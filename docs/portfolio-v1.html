wyrd-tui

32K lines · 51 test files · Solo
A property graph store with a hand-written Cypher query engine, Git sync, and a full terminal UI. In Go, a language I'd never used before starting this project.
Go 1.25 Bubble Tea v2 Cypher parser graph store custom merge driver plugin protocol
Tasks, notes, habits, journal entries, and budget envelopes are all nodes in a flat-file property graph, connected by typed edges. The query engine supports MATCH, WHERE, RETURN, ORDER BY, LIMIT, UNION, aggregation functions, variable-length path traversal, and date arithmetic; all via a hand-written lexer and recursive-descent parser. Individual JSONC files per node/edge, loaded into an in-memory index at startup with O(1) edge lookups, kept live via filesystem watcher. Git-based sync includes a custom three-way JSONC merge driver (a separate binary). Plugins communicate over JSON-lines via stdin/stdout; any language can extend the system.
The theme system is built from Reasonable Colors (LCH colour space, WCAG AA contrast) and degrades gracefully to 16-colour terminals. The schedule view uses time displacement: overruns visibly compress remaining tasks rather than hiding them.

How I Work with AI

AI as collaborator, not autocomplete

Claude appears as a git contributor across my projects. Every significant codebase includes a CLAUDE.md onboarding document that gives the AI the same context a new team member would need: architecture decisions, naming conventions, known constraints, what to avoid. These aren't templates; they're project-specific, often running to hundreds of lines, and maintained alongside the code.

Rhea is itself an AI-powered curriculum tool. I use structured XML prompt templates for complex multi-step workflows. The pattern is consistent: I do the architectural thinking and domain modelling; AI handles the implementation volume and catches what I miss. The spec-first approach (detailed design docs before code) works particularly well with this workflow; the spec becomes shared context that both human and AI can reason against.
